# HPC Website — mid-fidelity wireframe

Next.js (App Router) build of the new High Performance Coatings site. This is
a **mid-fidelity wireframe**, not the final production build: real layout,
real navigation, real photos, and draft copy — not final brand polish, and
not yet the final CMS decision (see the WordPress-vs-Next.js comparison in
the proposal doc under `HPC Sitemap`).

## Status

Built so far (first milestone — deliberately scoped small to get feedback
before templating out the rest):

- **Global nav** (`src/components/Header.jsx`) — full mega-menu matching the
  confirmed IA (`src/data/nav.js`): Residential, Commercial & Industrial,
  Gallery, Resources, About, Contact. Desktop hover dropdowns + mobile
  accordion, both functional.
- **Footer** (`src/components/Footer.jsx`)
- **Home page** (`src/app/page.js`) — hero, audience split, services grid,
  featured work strip, stats, mural spotlight (Lake Byllesby Pavilion), CTA.
- **Gallery page** (`src/app/gallery/page.js`) — working multi-facet filter
  (Audience / Service Type / Space / Finish) over 71 real tagged projects,
  lightbox with "copy shareable link".

**Not built yet**: every other nav destination (Residential/Commercial hub
pages, Resources, About, Contact, footer legal pages) — those routes exist in
the nav data but 404 until templated out in the next pass.

## Content & data

- `src/data/nav.js` — nav structure, mirrors the Proposed Navigation IA from
  the `HPC Sitemap` project.
- `src/data/projects.json` — gallery data, generated by
  `scripts/build-projects.py`. Re-run that script to regenerate from the
  source photo libraries (murals-source, the site scrape, and a curated pick
  of the Drive/Facebook photo batches) — see that project's
  `scrape/photo-quality-report.md` for what was excluded and why.
- `public/gallery/` — resized/optimized (max 1600px, JPEG q82) copies of the
  source photos, organized by bucket (`murals/`, `site/`, `curated/`).

## Auto-tagging caveat

Gallery tagging is a first pass ("auto-tag from what we know," not exhaustive
manual review): the Lake Byllesby mural and every site-scrape photo are
accurately tagged via their source; the drive-2017 and facebook-new photos
are a hand-curated subset (~45) tagged from what was visually reviewed via
contact sheets earlier in the project — the remaining ~375 photos in those
two folders aren't in the gallery yet. Expanding coverage is a follow-up
pass, not a blocker for this wireframe milestone.

## Murals

Only the Lake Byllesby Pavilion ceiling mural (from the Clubhaus case study,
with its process video) is on the site. The Mural Division portfolio PDF
projects -- Fargo ANG hangar, Marthaler Farms tank, school murals,
Crossroads Church, restaurant/retail -- were pulled for now; the source
images are still in `HPC Sitemap/murals-source/` and can be re-added in
`scripts/build-projects.py`.

## Spray-paint effect

`src/lib/spray.js` is a pointillist spray engine: a single nozzle makes one
right-to-left pass, round solid dots land around it in a gaussian cloud
(loose overspray ahead of the front, dense behind it), and the fill builds by
more dots landing -- nothing grows. A short wet-out at the end closes
pinholes. Behavior is modeled on the "Spray Dots Effect" project's
`SprayFillCanvas`. `SprayFillBand` (scroll-triggered stripes / full-section
fills) and `SprayHoverFill` (reversible button hover) draw with it. An
earlier port of RocoFoam's spray (circles growing until they merge) read as
foam, so it was dropped.
